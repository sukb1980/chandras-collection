# Chandra’s Collection — Handcrafted Heritage Sarees & Weaves of India

> Inspired by **Taneira (by Titan)**, **Chandra’s Collection** is a luxury ethnic e-commerce platform dedicated to India's timeless handloom traditions. Featuring pure mulberry silks, temple Kanjivarams, gossamer Chanderis, wild Tussars, and masterweaves from 40+ artisan clusters across India.

---

## 🌟 Key Features

### 1. Royal Brand Identity & Logo
- **Crest Design**: Stylized celestial Moon (*Chandra*) interwoven with royal Indian zari motifs, lotus petals, and radiant handloom warp threads.
- **Typography & Aesthetics**: Regally typeset in *Cinzel* & *Playfair Display* with a rich palette of Imperial Crimson Maroon (`#7B1123`), Burnished Zari Gold (`#C99738`), Pure Silk Raw Ivory (`#FAF7F2`), and Royal Emerald (`#1B4332`).

### 2. Two Types of Users
#### **A. Admin Console**
- **Add New Sarees**:
  - Category selection (Banarasi Silk, Kanjeevaram, Chanderi, Tussar, Organza, Paithani, etc.)
  - Multiple image upload & rich preset saree photography picker
  - Details, artisan lore, weaving craft technique, and weave time
  - Origin of the saree (cluster town & Indian state)
  - Material & fabric purity specification (e.g. 100% Pure Mulberry Silk, tested 24K gold zari)
  - Stock count management
  - Cost in ₹ INR with MRP and discount calculation
  - Silk Mark certification toggle
- **Inventory Oversight**: Real-time stock count adjuster (`+` / `-`), edit modal, and safe delete.
- **5-Day Pre-booking Registry**: Live log of customer reservations with time remaining.
- **Demo Reset**: Single-click button to restore the original curated collection.

#### **B. Normal User (Guest vs Logged-In)**
- **Guest User**:
  - Full catalog browsing, rich search, filtering by craft origin, material, and price range.
  - Multi-angle drape preview and artisan stories.
  - Clicking "Pre-book" or "Wishlist" prompts instant sign-in.
- **Logged-In User (Gmail or Facebook)**:
  - Sign in using **Gmail (Google)** or **Facebook** (with 1-click realistic OAuth simulation).
  - Create and manage a personal **Wishlist**.
  - **Exclusive 5-Day Pre-Booking**:
    - Hold any in-stock handcrafted saree for **5 days** with **zero upfront deposit**.
    - Live countdown timer displays exact days, hours, minutes, and seconds remaining.
    - **Automated Revocation**: If the 5 days pass without purchase, the pre-booking is **automatically revoked** and returned to public inventory.
    - **Simulation Button**: Includes a **"Simulate 5 Days Passed"** button on reservation cards to immediately test auto-revocation without waiting 5 real days.

### 3. Mock Online Purchase Screen (Indian Payment Gateway SDK)
- Modeled after **Razorpay / Cashfree / PayU**:
  - **UPI (Instant)**: Google Pay, PhonePe, Paytm, BHIM, enter UPI ID / VPA, or scan simulated dynamic QR code.
  - **Debit / Credit Cards**: RuPay, Visa, Mastercard with card number auto-formatting, CVV, and 1-click **"Fill Demo Test Card"** button.
  - **Net Banking**: HDFC Bank, SBI, ICICI Bank, Axis Bank, Kotak, PNB, and dropdown.
  - **Wallets & PayLater**: Paytm, MobiKwik, Simpl No-Cost EMI.
  - **Bank 3D Secure OTP Simulation**: Realistic RBI 2-factor OTP verification (`123456`).
  - **Order Confirmation & GST Tax Invoice**: Downloadable and printable GST invoice featuring HSN 5007 silk classification, 5% Handloom GST, free transit insurance, and order tracking.

### 4. Fully Responsive Design
- Optimized for mobile phones (320px+), tablets (iPad, Android tablets), and desktop monitors.
- Mobile search drawer, touch-friendly filter bars, and responsive grid layouts.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ & npm

### Installation
```bash
# Clone the repository
git clone https://github.com/sukb1980/sorbet-future-pwa.git
cd "New project"

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```

### Deployment to GitHub Pages
```bash
npm run deploy
```
